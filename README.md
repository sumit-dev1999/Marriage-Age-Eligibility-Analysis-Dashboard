## 3. Project Overview

The Marriage Age Eligibility Checker is an Excel-based project designed to evaluate marriage age eligibility based on gender and age criteria.

The dataset contains 200 individuals, including 100 males and 100 females. Excel logical functions are used to automatically determine eligibility according to the minimum age criteria defined in this project.

The project also includes an analysis sheet to summarize eligible and not eligible individuals, compare gender-wise eligibility, calculate eligibility percentages, and visualize the results through charts.

## 5. Dataset Information

| Column | Description |
|---|---|
| ID | Unique identification number |
| Full Name | Individual's full name |
| Gender | Male or Female |
| Age | Age of the individual |
| Minimum Required Age | Minimum age criteria based on gender |
| Eligibility | Eligible or Not Eligible |

### Eligibility Criteria

| Gender | Minimum Age | Eligibility Status |
|---|---:|---|
| Male | 21 Years | Eligible at 21 or above |
| Female | 18 Years | Eligible at 18 or above |

The criteria above are the rules defined for this Excel practice project.
